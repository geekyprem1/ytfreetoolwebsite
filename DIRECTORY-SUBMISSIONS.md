## 3. Submission rules (reject na ho)

1. **Har jagah SAME name + SAME domain** — `YT Toolkit` + ek canonical URL. `yttoolkit.com` ek jagah aur `yttools.pro` dusri jagah = duplicate listing reject.
2. **Description spin karo, copy-paste same long text har jagah mat daalo** — short wala same chalega, long wale me 2-3 variants banao (upar wale me sirf pehla paragraph badal do).
3. **Category galat mat chunna** — "AI" har jagah thokne se reject hota hai. Downloader wali listing me Video/Utility chuno, AI wali me AI/Writing.
4. **Screenshot bina submit mat karo** jaha optional bhi ho — bina screenshot wali listing 3x zyada reject hoti hai.
5. **Paid walo ka order:** budget hai to Toolify ($99) > TAAFT fast-track > Futurepedia. Baaki sab free se start karo.
